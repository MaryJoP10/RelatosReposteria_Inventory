# relatos

Sistema de gestión y análisis para emprendimientos de repostería.

## Características
- Gestión de inventario
- Recetas
- Producción
- Productos terminados
- Compras
- Ventas
- Gastos
- Dashboard y análisis

## Tecnologías
- Flutter
- Dart
- SQLite
- PWA
- SharedPreferences
